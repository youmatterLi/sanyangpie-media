# Privacy Policy — sanyangpie-publisher

Last updated: 8 August 2026

sanyangpie-publisher is a private command-line tool used solely by its author
to upload her own podcast content to her own YouTube channel and Instagram account.

## No third-party users
This tool is not distributed, published, or made available to anyone else.
It has no user interface, no user accounts, and no sign-up process.

## Data collected
The tool collects no data from any person. It does not track users, does not
use cookies, and does not operate any server.

## YouTube API Services
This tool uses YouTube API Services. By using it, the author is bound by the
YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google
Privacy Policy (https://policies.google.com/privacy).

The only YouTube data stored is the video ID returned after a successful
upload, written to a local file to prevent duplicate uploads. No YouTube user
data of any other person is accessed, stored, or shared.

Authorisation credentials are stored locally on the author's own computer and
are never transmitted to any third party.

## Revoking access
Access can be revoked at any time via https://myaccount.google.com/permissions
